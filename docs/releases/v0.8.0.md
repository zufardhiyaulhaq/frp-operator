Releasing v0.8.0 FRP Operator 🥳🥳

Changes:
1. Environment variables for the FRP client pod via `podTemplate.env` on `Client` — set `GOMEMLIMIT` to keep `frpc` from being OOM-killed under high load, no mutating webhook required
2. Proxy Protocol (`proxyProtocol`) and `transport` (encryption, compression, bandwidth limit) support for UDP Upstreams, reaching parity with TCP
3. Multi-architecture operator image: `linux/amd64` and `linux/arm64`

## How to Upgrade

Helm by default doesn't update the CRDs, you need to apply the CRDs manually:
```
kubectl apply -f https://raw.githubusercontent.com/zufardhiyaulhaq/frp-operator/v0.8.0/charts/frp-operator/crds/crds.yaml
```

Example — limit the Go heap of the `frpc` container:
```yaml
spec:
  podTemplate:
    resources:
      limits:
        memory: "256Mi"
    env:
      - name: GOMEMLIMIT
        value: "200MiB"
```
