# frps Server CRD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Server` custom resource that runs frps (one pod, a public `LoadBalancer`/`ClusterIP` Service, an optional dashboard Service) so private clusters' Clients can connect to it, plus the Client-side `tls.serverName` and a fix for how Clients mount TLS files.

**Architecture:** A new package `pkg/frps` turns a `Server` into objects: `Validate` (port layout), `Resolve` (reads Secrets, renders `frps.toml`), and pure builders (pod, Services, Secrets, ServiceMonitor, config hash). A new `ServerReconciler` applies them, restarts frps when the config hash changes (frps cannot reload), and reports `Ready`/`ConfigSynced`. Client changes are small and self-contained (Task 1).

**Tech Stack:** Go 1.23, Kubebuilder v3, controller-runtime v0.18.4, k8s.io v0.30, frp v0.71.0 (`fatedier/frps`), Docker (frps/frpc verify), k3d (e2e).

**Spec:** `docs/superpowers/specs/2026-10-11-frps-server-design.md`

## Global Constraints

- frps image: `fatedier/frps:v0.71.0` — the same frp release as `frpcImage` (`fatedier/frpc:v0.71.0`). It is declared on its own line as `const Image = "fatedier/frps:v0.71.0"` in `pkg/frps/names.go` (the Makefile reads it with `sed`).
- No new Go module dependencies. The ServiceMonitor is built as `unstructured.Unstructured` (`monitoring.coreos.com/v1`). frp itself cannot be imported (needs Go 1.25).
- Every string rendered into TOML goes through the `quote` template function (`utils.TemplateFuncs`). Optional keys are omitted when unset.
- Every rendered `frps.toml` passes `frps verify` and every rendered `frpc.toml` passes `frpc verify`, from the pinned images (`make test-frpc-config`). New render paths get a case there.
- After `api/v1alpha1` changes: `make generate manifests`, then `cat config/crd/bases/frp.zufardhiyaulhaq.com_{clients,upstreams,visitors,serverpools,servers}.yaml > charts/frp-operator/crds/crds.yaml` (that order). RBAC is edited by hand in `charts/frp-operator/templates/clusterrole.yaml`.
- `README.md` and `charts/frp-operator/README.md` are generated by `make readme` from `charts/frp-operator/README.md.gotmpl`; edit the `.gotmpl` only.
- `pkg/client/utils/template_test.go` uses mirror structs (`testTLSConfig`, ...). A model field used by `CLIENT_TEMPLATE` must be added there too.
- Every `docs/superpowers/**/*.md` starts with a Liquid `raw` tag on its first line and ends with the matching `endraw` tag on its last line (GitHub Pages runs Liquid over Markdown). Never write either tag literally inside the body: it would close the block early.
- Kubernetes: only `--context orbstack` for manual checks; e2e only on the private k3d cluster (`make test-e2e`, kubeconfig `output/e2e-kubeconfig`). Never any other context.
- Commits: `git commit -s` (DCO) with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No push without the owner's OK.
- Spec ruling already folded into the spec (G8): non-root frps binds ports below 1024 through the pod sysctl `net.ipv4.ip_unprivileged_port_start=0`, not `NET_BIND_SERVICE` (Kubernetes grants no ambient capabilities to non-root processes).

## Review Focus

1. **Updating an existing Service** (LoadBalancer → ClusterIP, `externalTrafficPolicy` Local → Cluster, port list change) must not be rejected by the API server: node ports, `allocateLoadBalancerNodePorts`, `healthCheckNodePort` and `loadBalancerClass` are cleared or kept correctly. Pinned by `TestKeepNodePorts` (Task 5) and `TestServerReconcile_ServiceTypeChangeClearsLoadBalancerFields` (Task 6).
2. **Rotating a referenced certificate Secret** (cert-manager renewal) must restart frps under `Automatic`, because frps only reads certificates at start. Pinned by `TestServerReconcile_CertificateRotationRestartsPod` (Task 6).
3. **Generated credentials stay stable** across reconciles and operator restarts; only deleting `<server>-connection` rotates the token. Pinned by `TestResolve_GeneratesTokenOnce` (Task 3) and `TestServerReconcile_GeneratedTokenIsStable` / `..._DeletedConnectionSecretRotatesToken` (Task 6).
4. **`restartPolicy: Manual` must not leak a new config into the running pod** (the kubelet syncs mounted Secrets, so a crash restart would pick it up). Pinned by `TestServerReconcile_ManualRestartWaitsForPodDeletion` (Task 6), which asserts the config Secret is unchanged while pending.
5. **Existing Clients whose TLS `key` fields were ignored until now**: after Task 1 the key matters, so a wrong key must surface as `InvalidConfig`, not as a pod stuck in `ContainerCreating`. Pinned by `TestNewConfig_TLSMissingKeyIsAnError` (Task 1); the release notes must call it out.

```go
// projectedTLSFiles maps each file in the pod's tls-certs volume to "<kind>:<name>/<key>".
func projectedTLSFiles(t *testing.T, pod *corev1.Pod) map[string]string {
	t.Helper()
	for _, v := range pod.Spec.Volumes {
		if v.Name != "tls-certs" {
			continue
		}
		if v.Projected == nil {
			t.Fatalf("tls-certs volume is not projected: %+v", v.VolumeSource)
		}
		got := map[string]string{}
		for _, src := range v.Projected.Sources {
			switch {
			case src.Secret != nil:
				for _, it := range src.Secret.Items {
					got[it.Path] = "secret:" + src.Secret.Name + "/" + it.Key
				}
			case src.ConfigMap != nil:
				for _, it := range src.ConfigMap.Items {
					got[it.Path] = "configmap:" + src.ConfigMap.Name + "/" + it.Key
				}
			}
		}
		return got
	}
	return nil
}

func TestPodBuilder_TLSFilesFromSeparateSources(t *testing.T) {
	pod, err := NewPodBuilder().SetName("c").SetNamespace("ns").SetImage("img").
		SetTLS(&frpv1alpha1.ClientSpec_Server_TLS{
			Enable:        true,
			CertFile:      &frpv1alpha1.SecretRef{Secret: frpv1alpha1.Secret{Name: "client-cert", Key: "cert.pem"}},
			KeyFile:       &frpv1alpha1.SecretRef{Secret: frpv1alpha1.Secret{Name: "client-cert", Key: "key.pem"}},
			TrustedCAFile: &frpv1alpha1.ConfigMapOrSecretRef{Secret: &frpv1alpha1.Secret{Name: "server-ca", Key: "ca.crt"}},
		}).Build()
	if err != nil {
		t.Fatal(err)
	}
	want := map[string]string{
		"tls.crt": "secret:client-cert/cert.pem",
		"tls.key": "secret:client-cert/key.pem",
		"ca.crt":  "secret:server-ca/ca.crt",
	}
	if got := projectedTLSFiles(t, pod); !reflect.DeepEqual(got, want) {
		t.Errorf("TLS files = %v, want %v", got, want)
	}
	mounted := false
	for _, m := range pod.Spec.Containers[0].VolumeMounts {
		if m.Name == "tls-certs" && m.MountPath == "/etc/frp/tls" && m.ReadOnly {
			mounted = true
		}
	}
	if !mounted {
		t.Errorf("tls-certs is not mounted read-only at /etc/frp/tls: %+v", pod.Spec.Containers[0].VolumeMounts)
	}
}
```

```go
// configMapValue reads one key of a ConfigMap. A missing ConfigMap or key is an error.
func configMapValue(k8sclient client.Client, namespace string, ref frpv1alpha1.ConfigMapRef) (string, error) {
	cm := &corev1.ConfigMap{}
	if err := k8sclient.Get(context.TODO(), types.NamespacedName{Name: ref.Name, Namespace: namespace}, cm); err != nil {
		return "", err
	}
	if value, ok := cm.Data[ref.Key]; ok {
		return value, nil
	}
	if value, ok := cm.BinaryData[ref.Key]; ok {
		return string(value), nil
	}
	return "", errors.NewBadRequest(fmt.Sprintf("key %q not found in configmap %s/%s", ref.Key, namespace, ref.Name))
}
```

```go
// SetTLS mounts the Client's TLS files at /etc/frp/tls as tls.crt, tls.key and ca.crt, each read
// from its own Secret (or ConfigMap, for the CA) and key.
func (n *PodBuilder) SetTLS(tls *frpv1alpha1.ClientSpec_Server_TLS) *PodBuilder {
	n.TLS = tls
	return n
}

// tlsProjection lists the projected-volume sources for the TLS files that are set.
func tlsProjection(t *frpv1alpha1.ClientSpec_Server_TLS) []corev1.VolumeProjection {
	if t == nil {
		return nil
	}
	var sources []corev1.VolumeProjection
	secret := func(ref frpv1alpha1.Secret, path string) {
		sources = append(sources, corev1.VolumeProjection{Secret: &corev1.SecretProjection{
			LocalObjectReference: corev1.LocalObjectReference{Name: ref.Name},
			Items:                []corev1.KeyToPath{{Key: ref.Key, Path: path}},
		}})
	}
	if t.CertFile != nil {
		secret(t.CertFile.Secret, "tls.crt")
	}
	if t.KeyFile != nil {
		secret(t.KeyFile.Secret, "tls.key")
	}
	if ca := t.TrustedCAFile; ca != nil {
		switch {
		case ca.Secret != nil:
			secret(*ca.Secret, "ca.crt")
		case ca.ConfigMap != nil:
			sources = append(sources, corev1.VolumeProjection{ConfigMap: &corev1.ConfigMapProjection{
				LocalObjectReference: corev1.LocalObjectReference{Name: ca.ConfigMap.Name},
				Items:                []corev1.KeyToPath{{Key: ca.ConfigMap.Key, Path: "ca.crt"}},
			}})
		}
	}
	return sources
}
```

```go
// Package frps builds what the operator runs for a Server: frps.toml, the frps pod and its
// Services. Only Resolve talks to the API server (it reads Secrets); everything else is pure.
package frps

import (
	"fmt"
	"slices"
	"strconv"
	"strings"

	corev1 "k8s.io/api/core/v1"
	"k8s.io/apimachinery/pkg/util/intstr"

	v1 "github.com/zufardhiyaulhaq/frp-operator/api/v1alpha1"
)

// WebServerPort is where frps serves the dashboard, admin API and /metrics inside the pod.
const WebServerPort int32 = 7500

// LoadBalancerClass is the class the operator's own LoadBalancer controller claims. A Server's
// Service must not use it, or the operator would try to back its own frps with a ServerPool.
const LoadBalancerClass = "frp.zufardhiyaulhaq.com/frp"

// Ports is a Server's validated port layout. A zero port is off.
type Ports struct {
	Bind, KCP, QUIC     int32
	HTTP, HTTPS, TCPMux int32
	AllowTCP, AllowUDP  []int32 // sorted, unique
	WebServer           bool    // dashboard or metrics: frps listens on WebServerPort
}

// PortSpan is one entry of frps's allowPorts.
type PortSpan struct{ Start, End int32 }

// ParsePortRange parses "443" or "8000-8010".
func ParsePortRange(r v1.PortRange) (int32, int32, error) {
	first, last, isRange := strings.Cut(string(r), "-")
	start, err := strconv.Atoi(first)
	if err != nil {
		return 0, 0, fmt.Errorf("port range %q: %w", r, err)
	}
	end := start
	if isRange {
		if end, err = strconv.Atoi(last); err != nil {
			return 0, 0, fmt.Errorf("port range %q: %w", r, err)
		}
	}
	if start < 1 || end > 65535 || start > end {
		return 0, 0, fmt.Errorf("port range %q must be within 1-65535 with start <= end", r)
	}
	return int32(start), int32(end), nil
}

func expand(field string, ranges []v1.PortRange) ([]int32, error) {
	var ports []int32
	for _, r := range ranges {
		start, end, err := ParsePortRange(r)
		if err != nil {
			return nil, fmt.Errorf("%s: %w", field, err)
		}
		for p := start; p <= end; p++ {
			ports = append(ports, p)
		}
	}
	slices.Sort(ports)
	return slices.Compact(ports), nil
}

// WebServerEnabled reports whether frps runs its web server (dashboard or metrics).
func WebServerEnabled(spec *v1.ServerSpec) bool {
	return (spec.Dashboard != nil && spec.Dashboard.Enabled) || (spec.Metrics != nil && spec.Metrics.Enabled)
}

// Validate checks a Server spec and returns its port layout. maxPorts caps the public Service.
func Validate(spec *v1.ServerSpec, maxPorts int) (*Ports, error) {
	if s := spec.Service; s != nil {
		if s.Type != "" && s.Type != string(corev1.ServiceTypeLoadBalancer) && s.Type != string(corev1.ServiceTypeClusterIP) {
			return nil, fmt.Errorf("service.type %q is not supported: use LoadBalancer or ClusterIP (NodePort remaps ports, and frps opens each remote port itself)", s.Type)
		}
		if s.LoadBalancerClass == LoadBalancerClass {
			return nil, fmt.Errorf("service.loadBalancerClass %q is the operator's own ServerPool class", s.LoadBalancerClass)
		}
	}
	if m := spec.Metrics; m != nil && m.ServiceMonitor && !m.Enabled {
		return nil, fmt.Errorf("metrics.serviceMonitor requires metrics.enabled")
	}

	p := &Ports{Bind: spec.Bind.Port, KCP: deref(spec.Bind.KCPPort), QUIC: deref(spec.Bind.QUICPort), WebServer: WebServerEnabled(spec)}
	if p.Bind == 0 {
		return nil, fmt.Errorf("bind.port is required")
	}
	if v := spec.Vhost; v != nil {
		p.HTTP, p.HTTPS, p.TCPMux = deref(v.HTTPPort), deref(v.HTTPSPort), deref(v.TCPMuxPort)
	}
	if a := spec.AllowPorts; a != nil {
		var err error
		if p.AllowTCP, err = expand("allowPorts.tcp", a.TCP); err != nil {
			return nil, err
		}
		if p.AllowUDP, err = expand("allowPorts.udp", a.UDP); err != nil {
			return nil, err
		}
	}

	tcp := []portUse{{p.Bind, "bind.port"}, {p.HTTP, "vhost.httpPort"}, {p.HTTPS, "vhost.httpsPort"}, {p.TCPMux, "vhost.tcpmuxPort"}}
	if p.WebServer {
		tcp = append(tcp, portUse{WebServerPort, "the dashboard/metrics web server"})
	}
	for _, port := range p.AllowTCP {
		tcp = append(tcp, portUse{port, "allowPorts.tcp"})
	}
	udp := []portUse{{p.KCP, "bind.kcpPort"}, {p.QUIC, "bind.quicPort"}}
	for _, port := range p.AllowUDP {
		udp = append(udp, portUse{port, "allowPorts.udp"})
	}
	if err := noOverlap("TCP", tcp); err != nil {
		return nil, err
	}
	if err := noOverlap("UDP", udp); err != nil {
		return nil, err
	}

	if n := len(p.ServicePorts()); n > maxPorts {
		return nil, fmt.Errorf("the public Service would have %d ports, more than --server-max-ports=%d", n, maxPorts)
	}
	return p, nil
}

type portUse struct {
	port int32
	what string
}

// noOverlap rejects a port used twice within one protocol; TCP and UDP are separate in frps.
func noOverlap(proto string, uses []portUse) error {
	seen := map[int32]string{}
	for _, u := range uses {
		if u.port == 0 {
			continue
		}
		if u.port < 1 || u.port > 65535 {
			return fmt.Errorf("%s %d is outside 1-65535", u.what, u.port)
		}
		if prev, ok := seen[u.port]; ok {
			return fmt.Errorf("%s port %d is used by both %s and %s", proto, u.port, prev, u.what)
		}
		seen[u.port] = u.what
	}
	return nil
}

// ServicePorts are the public Service's ports, each with its own protocol.
func (p *Ports) ServicePorts() []corev1.ServicePort {
	var out []corev1.ServicePort
	add := func(name string, port int32, proto corev1.Protocol) {
		if port != 0 {
			out = append(out, corev1.ServicePort{Name: name, Port: port, TargetPort: intstr.FromInt32(port), Protocol: proto})
		}
	}
	add("bind", p.Bind, corev1.ProtocolTCP)
	add("kcp", p.KCP, corev1.ProtocolUDP)
	add("quic", p.QUIC, corev1.ProtocolUDP)
	add("http", p.HTTP, corev1.ProtocolTCP)
	add("https", p.HTTPS, corev1.ProtocolTCP)
	add("tcpmux", p.TCPMux, corev1.ProtocolTCP)
	for _, port := range p.AllowTCP {
		add(fmt.Sprintf("tcp-%d", port), port, corev1.ProtocolTCP)
	}
	for _, port := range p.AllowUDP {
		add(fmt.Sprintf("udp-%d", port), port, corev1.ProtocolUDP)
	}
	return out
}

// AllowRanges is frps's allowPorts: the union of the TCP and UDP ports, merged into spans. With
// no ports it is the empty span {2, 1}, because an empty allowPorts makes frps allow every port.
func (p *Ports) AllowRanges() []PortSpan {
	ports := slices.Concat(p.AllowTCP, p.AllowUDP)
	slices.Sort(ports)
	ports = slices.Compact(ports)
	if len(ports) == 0 {
		return []PortSpan{{Start: 2, End: 1}}
	}
	spans := []PortSpan{{Start: ports[0], End: ports[0]}}
	for _, port := range ports[1:] {
		if last := &spans[len(spans)-1]; port == last.End+1 {
			last.End = port
		} else {
```

```go
// Package frpstest has helpers for tests that need TLS material for a Server.
package frpstest

import (
	"crypto/ecdsa"
	"crypto/elliptic"
	"crypto/rand"
	"crypto/x509"
	"crypto/x509/pkix"
	"encoding/pem"
	"math/big"
	"time"
)

// SelfSigned returns a fresh self-signed certificate and key (PEM) for dnsNames, valid for a day.
// The certificate is its own CA, so it can also be published as ca.crt.
func SelfSigned(dnsNames ...string) (certPEM, keyPEM []byte, err error) {
	key, err := ecdsa.GenerateKey(elliptic.P256(), rand.Reader)
	if err != nil {
		return nil, nil, err
	}
	serial, err := rand.Int(rand.Reader, new(big.Int).Lsh(big.NewInt(1), 62))
	if err != nil {
		return nil, nil, err
	}
	tmpl := &x509.Certificate{
		SerialNumber:          serial,
		Subject:               pkix.Name{CommonName: "frps"},
		DNSNames:              dnsNames,
		NotBefore:             time.Now().Add(-time.Hour),
		NotAfter:              time.Now().Add(24 * time.Hour),
		KeyUsage:              x509.KeyUsageDigitalSignature | x509.KeyUsageCertSign,
		ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
		BasicConstraintsValid: true,
		IsCA:                  true,
	}
	der, err := x509.CreateCertificate(rand.Reader, tmpl, tmpl, &key.PublicKey, key)
	if err != nil {
		return nil, nil, err
	}
	keyDER, err := x509.MarshalECPrivateKey(key)
	if err != nil {
		return nil, nil, err
	}
	return pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: der}),
		pem.EncodeToMemory(&pem.Block{Type: "EC PRIVATE KEY", Bytes: keyDER}), nil
}
```

```go
	WebServer     *WebServerConfig // nil: no dashboard, admin API or metrics

// Render renders frps.toml.
func Render(c Config) (string, error) {
	tmpl, err := template.New("frps").Funcs(utils.TemplateFuncs).Parse(FRPS_TEMPLATE)
	if err != nil {
		return "", err
	}
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, c); err != nil {
		return "", err
	}
	return buf.String(), nil
}
```

```go
// ServerNames checks that certPEM and keyPEM are a matching pair and returns the certificate's
// DNS names, which a Client puts in tls.serverName.
func ServerNames(certPEM, keyPEM []byte) ([]string, error) {
	pair, err := tls.X509KeyPair(certPEM, keyPEM)
	if err != nil {
		return nil, err
	}
	leaf, err := x509.ParseCertificate(pair.Certificate[0])
	if err != nil {
		return nil, err
	}
	return leaf.DNSNames, nil
}
```

```go
package frps

import (
	"context"
	"crypto/rand"
	"crypto/tls"
	"encoding/hex"
	"fmt"

	corev1 "k8s.io/api/core/v1"
	apierrors "k8s.io/apimachinery/pkg/api/errors"

)

// Credentials are the web server's basic-auth login.
type Credentials struct{ Username, Password string }

// Resolved is a Server with every Secret it references read, ready to build objects from.
type Resolved struct {
	Ports        *Ports
	TOML         string
	Token        string
	NewToken     bool              // generated by this call: no token was stored yet
	ConnectionCA []byte            // ca.crt of bind.tls.certificate; nil when it has none
	ServerNames  []string          // DNS names of bind.tls.certificate
	Dashboard    *Credentials      // nil when the web server is off
	GeneratedDashboard bool        // Dashboard lives in <server>-dashboard (credentials not set)
	Mounted      map[string][]byte // "<secret>/<key>" → every Secret file mounted into the frps pod
}

// Resolve validates s and reads every Secret it references. An error means the spec cannot be
// applied (InvalidConfig). Resolve writes nothing.
func Resolve(ctx context.Context, c client.Client, s *v1.Server, maxPorts int) (*Resolved, error) {
	ports, err := Validate(&s.Spec, maxPorts)
	if err != nil {
		return nil, err
	}
	r := &Resolved{Ports: ports, Mounted: map[string][]byte{}}
	cfg := Config{Ports: ports}
	if v := s.Spec.Vhost; v != nil {
		cfg.SubdomainHost = v.SubdomainHost
	}

	if err := r.resolveToken(ctx, c, s); err != nil {
		return nil, err
	}
	cfg.Token = r.Token

	if t := s.Spec.Bind.TLS; t != nil {
		cfg.TLS = &TLSConfig{Force: t.Force == nil || *t.Force}
		if t.Certificate != nil {
			name := t.Certificate.Secret.Name
			crt, key, data, err := r.certificate(ctx, c, s.Namespace, name)
			if err != nil {
				return nil, fmt.Errorf("bind.tls.certificate: %w", err)
			}
			if r.ServerNames, err = ServerNames(crt, key); err != nil {
				return nil, fmt.Errorf("bind.tls.certificate %s/%s: %w", s.Namespace, name, err)
			}
			r.ConnectionCA = data["ca.crt"]
			cfg.TLS.CertFile, cfg.TLS.KeyFile = TLSDir+"/tls.crt", TLSDir+"/tls.key"
		}
		if t.ClientCA != nil {
			name := t.ClientCA.Secret.Name
			data, err := getSecret(ctx, c, s.Namespace, name)
			if err != nil {
				return nil, fmt.Errorf("bind.tls.clientCA: %w", err)
			}
			ca, err := need(data, s.Namespace, name, "ca.crt")
			if err != nil {
				return nil, fmt.Errorf("bind.tls.clientCA: %w", err)
			}
			r.Mounted[name+"/ca.crt"] = ca
			cfg.TLS.TrustedCAFile = TLSDir + "/ca.crt"
		}
	}

	if ports.WebServer {
		if cfg.WebServer, err = r.resolveWebServer(ctx, c, s); err != nil {
			return nil, err
		}
	}

	if r.TOML, err = Render(cfg); err != nil {
		return nil, err
	}
	return r, nil
}

func (r *Resolved) resolveToken(ctx context.Context, c client.Client, s *v1.Server) error {
	if a := s.Spec.Authentication; a != nil && a.Token != nil {
		ref := a.Token.Secret
		data, err := getSecret(ctx, c, s.Namespace, ref.Name)
		if err != nil {
			return fmt.Errorf("authentication.token: %w", err)
		}
		v, err := need(data, s.Namespace, ref.Name, ref.Key)
		if err != nil {
			return fmt.Errorf("authentication.token: %w", err)
		}
		if len(v) == 0 {
			return fmt.Errorf("authentication.token: key %q in secret %s/%s is empty", ref.Key, s.Namespace, ref.Name)
		}
		r.Token = string(v)
		return nil
	}
	stored, err := getOptionalSecret(ctx, c, s.Namespace, ConnectionSecretName(s))
	if err != nil {
		return err
	}
	if token := stored["token"]; len(token) > 0 {
		r.Token = string(token)
		return nil
	}
	r.Token, r.NewToken = randomHex(32), true
	return nil
}

func (r *Resolved) resolveWebServer(ctx context.Context, c client.Client, s *v1.Server) (*WebServerConfig, error) {
	web := &WebServerConfig{Port: WebServerPort, Prometheus: s.Spec.Metrics != nil && s.Spec.Metrics.Enabled}
	d := s.Spec.Dashboard
	if d != nil && d.Credentials != nil {
		name := d.Credentials.Secret.Name
		data, err := getSecret(ctx, c, s.Namespace, name)
		if err != nil {
			return nil, fmt.Errorf("dashboard.credentials: %w", err)
		}
		user, err := need(data, s.Namespace, name, "username")
		if err != nil {
			return nil, fmt.Errorf("dashboard.credentials: %w", err)
		}
		password, err := need(data, s.Namespace, name, "password")
		if err != nil {
			return nil, fmt.Errorf("dashboard.credentials: %w", err)
		}
		r.Dashboard = &Credentials{Username: string(user), Password: string(password)}
	} else {
		r.GeneratedDashboard = true
		stored, err := getOptionalSecret(ctx, c, s.Namespace, DashboardSecretName(s))
		if err != nil {
			return nil, err
		}
		if len(stored["username"]) > 0 && len(stored["password"]) > 0 {
			r.Dashboard = &Credentials{Username: string(stored["username"]), Password: string(stored["password"])}
		} else {
			r.Dashboard = &Credentials{Username: "admin", Password: randomHex(16)}
		}
	}
	web.User, web.Password = r.Dashboard.Username, r.Dashboard.Password

	if d != nil && d.TLS != nil {
		name := d.TLS.Certificate.Secret.Name
		crt, key, _, err := r.certificate(ctx, c, s.Namespace, name)
		if err != nil {
			return nil, fmt.Errorf("dashboard.tls.certificate: %w", err)
		}
		if _, err := tls.X509KeyPair(crt, key); err != nil {
			return nil, fmt.Errorf("dashboard.tls.certificate %s/%s: %w", s.Namespace, name, err)
		}
		web.CertFile, web.KeyFile = DashboardTLSDir+"/tls.crt", DashboardTLSDir+"/tls.key"
	}
	return web, nil
}

// certificate reads tls.crt and tls.key from a Secret and records both as mounted.
func (r *Resolved) certificate(ctx context.Context, c client.Client, namespace, name string) (crt, key []byte, data map[string][]byte, err error) {
	if data, err = getSecret(ctx, c, namespace, name); err != nil {
		return nil, nil, nil, err
	}
	if crt, err = need(data, namespace, name, "tls.crt"); err != nil {
		return nil, nil, nil, err
	}
	if key, err = need(data, namespace, name, "tls.key"); err != nil {
		return nil, nil, nil, err
	}
	r.Mounted[name+"/tls.crt"], r.Mounted[name+"/tls.key"] = crt, key
	return crt, key, data, nil
}

func getSecret(ctx context.Context, c client.Client, namespace, name string) (map[string][]byte, error) {
	s := &corev1.Secret{}
	if err := c.Get(ctx, types.NamespacedName{Namespace: namespace, Name: name}, s); err != nil {
		return nil, fmt.Errorf("secret %s/%s: %w", namespace, name, err)
	}
	return s.Data, nil
}

// getOptionalSecret is getSecret where a missing Secret is nil data, not an error.
func getOptionalSecret(ctx context.Context, c client.Client, namespace, name string) (map[string][]byte, error) {
	s := &corev1.Secret{}
	if err := c.Get(ctx, types.NamespacedName{Namespace: namespace, Name: name}, s); err != nil {
		if apierrors.IsNotFound(err) {
			return nil, nil
		}
		return nil, fmt.Errorf("secret %s/%s: %w", namespace, name, err)
	}
	return s.Data, nil
}

func need(data map[string][]byte, namespace, name, key string) ([]byte, error) {
	v, ok := data[key]
	if !ok {
		return nil, fmt.Errorf("key %q not found in secret %s/%s", key, namespace, name)
	}
	return v, nil
}

// randomHex returns n random bytes as hex (2n characters).
func randomHex(n int) string {
	b := make([]byte, n)
	if _, err := rand.Read(b); err != nil {
		panic(fmt.Sprintf("crypto/rand: %v", err))
	}
	return hex.EncodeToString(b)
}
```

```go
// binaryVerify runs `<binary> verify` (frpc or frps) on every *.toml in dir inside a single
// container and returns the combined output per file name.
func binaryVerify(t *testing.T, image, binary, dir string) map[string]string {
	t.Helper()
	script := `for f in /c/*.toml; do echo "### $(basename "$f")"; /usr/bin/` + binary + ` verify -c "$f" 2>&1; done`
	cmd := exec.Command("docker", "run", "--rm", "-v", dir+":/c:ro", "--entrypoint", "sh", image, "-c", script)
	var out bytes.Buffer
	cmd.Stdout, cmd.Stderr = &out, &out
	if err := cmd.Run(); err != nil {
		t.Fatalf("docker run %s: %v\n%s", image, err, out.String())
	}

	results := map[string]string{}
	text := out.String()
	locs := verifyMarker.FindAllStringSubmatchIndex(text, -1)
	for i, loc := range locs {
		end := len(text)
		if i+1 < len(locs) {
			end = locs[i+1][0]
		}
		results[text[loc[2]:loc[3]]] = text[loc[1]:end]
	}
	return results
}
```

```go
import (
```

```go
// Apply merges t into pod: labels and annotations are added (t wins), the first container gets
// t's resources and env, and the scheduling and security fields replace the pod's.
func Apply(pod *corev1.Pod, t *frpv1alpha1.ClientSpec_PodTemplate) {
	if t == nil {
		return
	}
	if len(t.Labels) > 0 && pod.Labels == nil {
		pod.Labels = map[string]string{}
	}
	for k, v := range t.Labels {
		pod.Labels[k] = v
	}
	if len(t.Annotations) > 0 && pod.Annotations == nil {
		pod.Annotations = map[string]string{}
	}
	for k, v := range t.Annotations {
		pod.Annotations[k] = v
	}
	if len(pod.Spec.Containers) > 0 {
		c := &pod.Spec.Containers[0]
		if t.Resources != nil {
			c.Resources = *t.Resources
		}
		if t.Env != nil {
			c.Env = t.Env
		}
	}
	if t.NodeSelector != nil {
		pod.Spec.NodeSelector = t.NodeSelector
	}
	if t.Tolerations != nil {
		pod.Spec.Tolerations = t.Tolerations
	}
	if t.Affinity != nil {
		pod.Spec.Affinity = t.Affinity
	}
	if t.ServiceAccountName != "" {
		pod.Spec.ServiceAccountName = t.ServiceAccountName
	}
	if t.ImagePullSecrets != nil {
		pod.Spec.ImagePullSecrets = t.ImagePullSecrets
	}
	if t.PriorityClassName != "" {
		pod.Spec.PriorityClassName = t.PriorityClassName
	}
	if t.SecurityContext != nil {
```

```go
	ReasonTunnelTLSUnverified       = "TunnelTLSUnverified"
	ReasonDashboardInsecure         = "DashboardInsecure"
	ReasonTokenRotated              = "TokenRotated"
	ReasonServiceMonitorUnavailable = "ServiceMonitorUnavailable"
)

// PodState reports whether the frps pod is ready, or what is wrong with it.
func PodState(p *corev1.Pod) (ready bool, problem string) {
	if p.Status.Phase == corev1.PodFailed {
		return false, fmt.Sprintf("frps pod failed: %s %s", p.Status.Reason, p.Status.Message)
	}
	for _, cs := range p.Status.ContainerStatuses {
		if w := cs.State.Waiting; w != nil && w.Reason != "" && w.Reason != "ContainerCreating" && w.Reason != "PodInitializing" {
			return false, fmt.Sprintf("container %s: %s: %s", cs.Name, w.Reason, w.Message)
		}
	}
	for _, c := range p.Status.Conditions {
		if c.Type == corev1.PodReady && c.Status == corev1.ConditionTrue {
			return true, ""
		}
	}
	return false, ""
}
```

```go
func secretFiles(name string, keys ...string) corev1.VolumeProjection {
	items := make([]corev1.KeyToPath, 0, len(keys))
	for _, k := range keys {
		items = append(items, corev1.KeyToPath{Key: k, Path: k})
	}
	return corev1.VolumeProjection{Secret: &corev1.SecretProjection{LocalObjectReference: corev1.LocalObjectReference{Name: name}, Items: items}}
}

func addProjected(pod *corev1.Pod, name, dir string, sources ...corev1.VolumeProjection) {
	pod.Spec.Volumes = append(pod.Spec.Volumes, corev1.Volume{Name: name,
		VolumeSource: corev1.VolumeSource{Projected: &corev1.ProjectedVolumeSource{Sources: sources}}})
	pod.Spec.Containers[0].VolumeMounts = append(pod.Spec.Containers[0].VolumeMounts,
		corev1.VolumeMount{Name: name, MountPath: dir, ReadOnly: true})
}

// BuildPod builds the frps pod. The caller adds ConfigHashAnnotation (see ConfigHash).
func BuildPod(s *v1.Server, ports *Ports) *corev1.Pod {
	var containerPorts []corev1.ContainerPort
	lowPort := false
	for _, sp := range ports.ServicePorts() {
		containerPorts = append(containerPorts, corev1.ContainerPort{Name: sp.Name, ContainerPort: sp.Port, Protocol: sp.Protocol})
		lowPort = lowPort || sp.Port < 1024
	}
	if ports.WebServer {
		containerPorts = append(containerPorts, corev1.ContainerPort{Name: "web", ContainerPort: WebServerPort, Protocol: corev1.ProtocolTCP})
	}

	yes, no, user := true, false, nonRootUser
	pod := &corev1.Pod{
		ObjectMeta: metav1.ObjectMeta{
			Name: PodName(s), Namespace: s.Namespace, Labels: Labels(s),
			Annotations: map[string]string{"sidecar.istio.io/inject": "false", "linkerd.io/inject": "disabled"},
		},
		Spec: corev1.PodSpec{
			Containers: []corev1.Container{{
				Name:         "frps",
				Image:        Image,
				Command:      []string{"frps", "-c", ConfigDir + "/frps.toml"},
				Ports:        containerPorts,
				VolumeMounts: []corev1.VolumeMount{{Name: "config", MountPath: ConfigDir, ReadOnly: true}},
				ReadinessProbe: &corev1.Probe{
					ProbeHandler:  corev1.ProbeHandler{TCPSocket: &corev1.TCPSocketAction{Port: intstr.FromInt32(ports.Bind)}},
					PeriodSeconds: 5,
				},
				SecurityContext: &corev1.SecurityContext{
					RunAsNonRoot:             &yes,
					RunAsUser:                &user,
					AllowPrivilegeEscalation: &no,
					ReadOnlyRootFilesystem:   &yes,
					Capabilities:             &corev1.Capabilities{Drop: []corev1.Capability{"ALL"}},
				},
			}},
			Volumes: []corev1.Volume{{Name: "config", VolumeSource: corev1.VolumeSource{
				Secret: &corev1.SecretVolumeSource{SecretName: ConfigSecretName(s)},
			}}},
		},
	}
	// A non-root process gets no added capabilities in Kubernetes (no ambient capabilities), so
	// ports below 1024 are opened with this namespaced, safe sysctl instead of NET_BIND_SERVICE.
	if lowPort {
		pod.Spec.SecurityContext = &corev1.PodSecurityContext{Sysctls: []corev1.Sysctl{{Name: "net.ipv4.ip_unprivileged_port_start", Value: "0"}}}
	}
	if t := s.Spec.Bind.TLS; t != nil {
		var sources []corev1.VolumeProjection
		if t.Certificate != nil {
			sources = append(sources, secretFiles(t.Certificate.Secret.Name, "tls.crt", "tls.key"))
		}
		if t.ClientCA != nil {
			sources = append(sources, secretFiles(t.ClientCA.Secret.Name, "ca.crt"))
		}
		if len(sources) > 0 {
			addProjected(pod, "tls", TLSDir, sources...)
		}
	}
	if d := s.Spec.Dashboard; ports.WebServer && d != nil && d.TLS != nil {
		addProjected(pod, "dashboard-tls", DashboardTLSDir, secretFiles(d.TLS.Certificate.Secret.Name, "tls.crt", "tls.key"))
	}

	podtemplate.Apply(pod, s.Spec.PodTemplate)
	pod.Labels[SelectorLabel] = s.Name // the Services select on it; a template must not change it
	return pod
}

// ConfigHash identifies everything a running frps pod was started with: frps.toml, the content of
// every mounted Secret file and the pod spec (image, resources, ...). frps cannot reload, so a
// different hash means a restart.
func ConfigHash(toml string, mounted map[string][]byte, spec corev1.PodSpec) string {
	h := sha256.New()
	fmt.Fprintf(h, "%s\x00", toml)
	for _, k := range slices.Sorted(maps.Keys(mounted)) {
		fmt.Fprintf(h, "%s\x00%s\x00", k, mounted[k])
	}
	specJSON, _ := json.Marshal(spec) // a PodSpec always marshals
	h.Write(specJSON)
	return hex.EncodeToString(h.Sum(nil))[:16]
}

// BuildServiceMonitor scrapes /metrics on the web Service with the dashboard credentials.

		"port":   "web",
		"path":   "/metrics",

			"password": map[string]interface{}{"name": secret, "key": "password"},
		},
	}
	if d := s.Spec.Dashboard; d != nil && d.TLS != nil {
		endpoint["scheme"] = "https"

		},
	}}

	sm.SetNamespace(s.Namespace)
	sm.SetLabels(Labels(s))
	return sm
}

// KeepNodePorts copies the node ports the API server allocated onto the desired ports with the
// same name and protocol, so an update does not reallocate them. ClusterIP has no node ports.
func KeepNodePorts(current, desired []corev1.ServicePort, t corev1.ServiceType) []corev1.ServicePort {
	if t == corev1.ServiceTypeClusterIP {
		return desired
	}
	for i := range desired {
		for _, c := range current {
			if c.Name == desired[i].Name && c.Protocol == desired[i].Protocol {
				desired[i].NodePort = c.NodePort
			}
		}
	}
	return desired
}

// Address is where frpc connects: the load balancer's IP or hostname ("" while pending), or the
// Service's DNS name for ClusterIP.
func Address(svc *corev1.Service) string {
	if svc.Spec.Type == corev1.ServiceTypeClusterIP {
		return svc.Name + "." + svc.Namespace + ".svc"
	}
	for _, in := range svc.Status.LoadBalancer.Ingress {
		if in.IP != "" {
			return in.IP
		}
		if in.Hostname != "" {
			return in.Hostname
		}
	}
	return ""
}

// DashboardInsecure reports a web server reachable outside the cluster without TLS.
func DashboardInsecure(s *v1.Server) bool {
	d := s.Spec.Dashboard
	if !WebServerEnabled(&s.Spec) || (d != nil && d.TLS != nil) {
		return false
	}
	return d != nil && d.Service != nil && (d.Service.Type == string(corev1.ServiceTypeNodePort) || d.Service.Type == string(corev1.ServiceTypeLoadBalancer))
}

// SecretNames are the Secrets a Server owns or reads; a change to any of them reconciles it.
func SecretNames(s *v1.Server) []string {

	if a := s.Spec.Authentication; a != nil && a.Token != nil {
		names = append(names, a.Token.Secret.Name)
	}
	if t := s.Spec.Bind.TLS; t != nil {
		if t.Certificate != nil {
			names = append(names, t.Certificate.Secret.Name)
		}
		if t.ClientCA != nil {
			names = append(names, t.ClientCA.Secret.Name)
		}
	}
	if d := s.Spec.Dashboard; d != nil {
		if d.Credentials != nil {
			names = append(names, d.Credentials.Secret.Name)
		}
		if d.TLS != nil {
			names = append(names, d.TLS.Certificate.Secret.Name)
		}
	}
	return names
}
```

```go
// ServerReconciler runs frps for each Server: one pod, its config, a public and a web Service.
type ServerReconciler struct {
	client.Client
	Scheme   *runtime.Scheme
	Recorder record.EventRecorder
	// MaxPorts caps the ports of a Server's public Service (--server-max-ports).
	MaxPorts int
	// LoadBalancerError returns the latest SyncLoadBalancerFailed message for a Service, or "".
	LoadBalancerError func(ctx context.Context, namespace, service string) (string, error)
	// ServiceMonitorAvailable reports whether the cluster serves monitoring.coreos.com/v1 ServiceMonitor.
	ServiceMonitorAvailable func() bool
}

//+kubebuilder:rbac:groups=frp.zufardhiyaulhaq.com,resources=servers,verbs=get;list;watch;create;update;patch;delete
//+kubebuilder:rbac:groups=frp.zufardhiyaulhaq.com,resources=servers/status,verbs=get;update;patch
//+kubebuilder:rbac:groups=frp.zufardhiyaulhaq.com,resources=servers/finalizers,verbs=update
//+kubebuilder:rbac:groups="",resources=events,verbs=create;patch;list
//+kubebuilder:rbac:groups=monitoring.coreos.com,resources=servicemonitors,verbs=get;list;watch;create;update;patch;delete

func (r *ServerReconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
	log := log.FromContext(ctx)
	srv := &frpv1alpha1.Server{}
	if err := r.Get(ctx, req.NamespacedName, srv); err != nil {
		return ctrl.Result{}, client.IgnoreNotFound(err)
	}

	res, err := frps.Resolve(ctx, r.Client, srv, r.MaxPorts)
	if err != nil {
		// The running pod keeps its last good configuration; say why the spec is not applied.
		msg := fmt.Sprintf("invalid configuration: %v", err)
		log.Error(err, "invalid server configuration")
		r.Recorder.Event(srv, corev1.EventTypeWarning, frps.ReasonInvalidConfig, msg)
		setServerCondition(srv, status.ConditionTypeConfigSync, metav1.ConditionFalse, frps.ReasonInvalidConfig, msg)
		if statusErr := r.Status().Update(ctx, srv); statusErr != nil {
			log.Error(statusErr, "failed to update server status")
		}
		return ctrl.Result{}, err
	}

	newGeneration := srv.Status.ObservedGeneration != srv.Generation
	if newGeneration {
		r.warnAboutSpec(srv)
	}
	if res.NewToken && srv.Status.ConnectionSecret != "" {
		r.Recorder.Eventf(srv, corev1.EventTypeWarning, frps.ReasonTokenRotated,
			"Secret %s was missing, so a new token was generated: copy it to every connected cluster", frps.ConnectionSecretName(srv))
	}

	if err := r.applySecret(ctx, srv, frps.BuildConnectionSecret(srv, res.Token, res.ConnectionCA)); err != nil {
		return ctrl.Result{}, err
	}
	if res.Dashboard != nil && res.GeneratedDashboard {
		if err := r.applySecret(ctx, srv, frps.BuildDashboardSecret(srv, *res.Dashboard)); err != nil {
			return ctrl.Result{}, err
		}
	}

	svc, err := r.applyService(ctx, srv, frps.BuildService(srv, res.Ports))
	if err != nil {
		return ctrl.Result{}, err
	}
	webService := frps.BuildWebService(srv)
	if res.Ports.WebServer {
		_, err = r.applyService(ctx, srv, webService)
	} else {
		err = r.deleteIfExists(ctx, webService)
	}
	if err != nil {
		return ctrl.Result{}, err
	}
	if err := r.reconcileServiceMonitor(ctx, srv, newGeneration); err != nil {
		return ctrl.Result{}, err
	}

	pod, pending, err := r.reconcilePod(ctx, srv, res)
	if err != nil {
		return ctrl.Result{}, err
	}
	if pending && !hasServerReason(srv, status.ConditionTypeConfigSync, frps.ReasonRestartPending) {
		r.Recorder.Eventf(srv, corev1.EventTypeNormal, frps.ReasonRestartPending,
			"The configuration changed: delete pod %s to apply it (restartPolicy Manual)", frps.PodName(srv))
	}

	address := frps.Address(svc)
	lbError := ""
	if address == "" && svc.Spec.Type == corev1.ServiceTypeLoadBalancer && r.LoadBalancerError != nil {
		if lbError, err = r.LoadBalancerError(ctx, svc.Namespace, svc.Name); err != nil {
			log.Error(err, "failed to read load balancer events")
			lbError = ""
		}
	}
	setServerStatus(srv, res, pod, pending, address, lbError)
	if err := r.Status().Update(ctx, srv); err != nil {
		return ctrl.Result{}, err
	}
	if pod == nil {
		return ctrl.Result{RequeueAfter: 5 * time.Second}, nil
	}
	return ctrl.Result{RequeueAfter: 30 * time.Second}, nil
}

// reconcilePod returns the running pod (nil while frps restarts) and whether a Manual restart is
// pending. The config Secret is written only when a pod is about to start, so a running pod's
// mounted config never changes under it — a crash restart under Manual keeps the old config.
func (r *ServerReconciler) reconcilePod(ctx context.Context, srv *frpv1alpha1.Server, res *frps.Resolved) (*corev1.Pod, bool, error) {
	desired := frps.BuildPod(srv, res.Ports)
	desired.Annotations[frps.ConfigHashAnnotation] = frps.ConfigHash(res.TOML, res.Mounted, desired.Spec)
	if err := controllerutil.SetControllerReference(srv, desired, r.Scheme); err != nil {
		return nil, false, err
	}

	current := &corev1.Pod{}
	err := r.Get(ctx, client.ObjectKeyFromObject(desired), current)
	if apierrors.IsNotFound(err) {
		if err := r.applySecret(ctx, srv, frps.BuildConfigSecret(srv, res.TOML)); err != nil {
			return nil, false, err
		}
		if err := r.Create(ctx, desired); err != nil {
			return nil, false, err
		}
		r.Recorder.Eventf(srv, corev1.EventTypeNormal, frps.ReasonPodCreated, "Started frps pod %s", desired.Name)
		return desired, false, nil
	}
	if err != nil {
		return nil, false, err
	}
	if current.DeletionTimestamp != nil {
		return nil, false, nil
	}
	if current.Annotations[frps.ConfigHashAnnotation] == desired.Annotations[frps.ConfigHashAnnotation] {
		return current, false, nil
	}
	if frps.RestartPolicy(srv) == frpv1alpha1.RestartPolicyManual {
		return current, true, nil
	}
	if err := r.Delete(ctx, current); err != nil && !apierrors.IsNotFound(err) {
		return nil, false, err
	}
	r.Recorder.Event(srv, corev1.EventTypeNormal, frps.ReasonRestarting, "The configuration changed: restarting frps")
	return nil, false, nil
}

func setServerStatus(srv *frpv1alpha1.Server, res *frps.Resolved, pod *corev1.Pod, pending bool, address, lbError string) {
	srv.Status.Address = address
	srv.Status.ConnectionSecret = frps.ConnectionSecretName(srv)
	srv.Status.ExposedPorts = &frpv1alpha1.ServerStatus_ExposedPorts{TCP: res.Ports.AllowTCP, UDP: res.Ports.AllowUDP}
	srv.Status.TLS = nil
	if len(res.ServerNames) > 0 {
		srv.Status.TLS = &frpv1alpha1.ServerStatus_TLS{ServerNames: res.ServerNames}
	}
	srv.Status.ObservedGeneration = srv.Generation

	switch {
	case pod == nil:
		setServerCondition(srv, status.ConditionTypeConfigSync, metav1.ConditionFalse, frps.ReasonRestarting, "Restarting frps with the new configuration")
	case pending:
		setServerCondition(srv, status.ConditionTypeConfigSync, metav1.ConditionFalse, frps.ReasonRestartPending,
			fmt.Sprintf("restartPolicy is Manual: delete pod %s to apply the new configuration", pod.Name))
	default:
		setServerCondition(srv, status.ConditionTypeConfigSync, metav1.ConditionTrue, frps.ReasonConfigApplied, "frps runs the current configuration")
	}

	ready, problem := false, ""
	if pod != nil {
		ready, problem = frps.PodState(pod)
	}
	switch {
	case problem != "":
		setServerCondition(srv, status.ConditionTypeReady, metav1.ConditionFalse, frps.ReasonPodFailed, problem)
	case !ready:
		setServerCondition(srv, status.ConditionTypeReady, metav1.ConditionFalse, frps.ReasonPodStarting, "Waiting for the frps pod to be ready")
	case address == "" && lbError != "":
		setServerCondition(srv, status.ConditionTypeReady, metav1.ConditionFalse, frps.ReasonLoadBalancerFailed, lbError)
	case address == "":
		setServerCondition(srv, status.ConditionTypeReady, metav1.ConditionFalse, frps.ReasonAddressPending, "Waiting for the load balancer to assign an address")
	default:
		setServerCondition(srv, status.ConditionTypeReady, metav1.ConditionTrue, frps.ReasonReady, "frps is reachable at "+address)
	}
}

// warnAboutSpec emits the spec's Warning events once per generation.
func (r *ServerReconciler) warnAboutSpec(srv *frpv1alpha1.Server) {
	if t := srv.Spec.Bind.TLS; t == nil || t.Certificate == nil {
		r.Recorder.Event(srv, corev1.EventTypeWarning, frps.ReasonTunnelTLSUnverified,
			"bind.tls.certificate is not set: frps uses a random certificate, so clients cannot verify the server they connect to")
	}
	if frps.DashboardInsecure(srv) {
		r.Recorder.Event(srv, corev1.EventTypeWarning, frps.ReasonDashboardInsecure,
			"The dashboard Service is reachable outside the cluster without dashboard.tls: its login and admin API travel in clear text")
	}
}

func (r *ServerReconciler) reconcileServiceMonitor(ctx context.Context, srv *frpv1alpha1.Server, newGeneration bool) error {
	want := srv.Spec.Metrics != nil && srv.Spec.Metrics.ServiceMonitor
	if r.ServiceMonitorAvailable == nil || !r.ServiceMonitorAvailable() {
		if want && newGeneration {
			r.Recorder.Event(srv, corev1.EventTypeWarning, frps.ReasonServiceMonitorUnavailable,
				"metrics.serviceMonitor is set, but the ServiceMonitor CRD (monitoring.coreos.com/v1) is not installed")
		}
		return nil
	}
	desired := frps.BuildServiceMonitor(srv)
	if !want {
		return r.deleteIfExists(ctx, desired)
	}
	current := &unstructured.Unstructured{}
	current.SetGroupVersionKind(desired.GroupVersionKind())
	current.SetNamespace(desired.GetNamespace())
	current.SetName(desired.GetName())
	_, err := controllerutil.CreateOrUpdate(ctx, r.Client, current, func() error {
		current.SetLabels(desired.GetLabels())
		current.Object["spec"] = desired.Object["spec"]
		return controllerutil.SetControllerReference(srv, current, r.Scheme)
	})
	return err
}

func (r *ServerReconciler) applySecret(ctx context.Context, srv *frpv1alpha1.Server, desired *corev1.Secret) error {
	secret := &corev1.Secret{ObjectMeta: metav1.ObjectMeta{Name: desired.Name, Namespace: desired.Namespace}}
	_, err := controllerutil.CreateOrUpdate(ctx, r.Client, secret, func() error {
		secret.Labels = desired.Labels
		if secret.Type == "" {
			secret.Type = desired.Type
		}
		secret.Data = desired.Data
		return controllerutil.SetControllerReference(srv, secret, r.Scheme)
	})
	return err
}

// applyService patches a Service in place (it is never recreated, so its IP survives) and clears
// the fields the API server rejects after a type or traffic-policy change.
func (r *ServerReconciler) applyService(ctx context.Context, srv *frpv1alpha1.Server, desired *corev1.Service) (*corev1.Service, error) {
	svc := &corev1.Service{ObjectMeta: metav1.ObjectMeta{Name: desired.Name, Namespace: desired.Namespace}}
	_, err := controllerutil.CreateOrUpdate(ctx, r.Client, svc, func() error {
		svc.Labels = desired.Labels
		if svc.Annotations == nil {
			svc.Annotations = map[string]string{}
		}
		for k, v := range desired.Annotations {
			svc.Annotations[k] = v
		}
		svc.Spec.Type = desired.Spec.Type
		svc.Spec.Selector = desired.Spec.Selector
		svc.Spec.Ports = frps.KeepNodePorts(svc.Spec.Ports, desired.Spec.Ports, desired.Spec.Type)
		svc.Spec.ExternalTrafficPolicy = desired.Spec.ExternalTrafficPolicy
		svc.Spec.LoadBalancerSourceRanges = desired.Spec.LoadBalancerSourceRanges
		if desired.Spec.Type == corev1.ServiceTypeLoadBalancer {
			if svc.Spec.LoadBalancerClass == nil { // immutable once set
				svc.Spec.LoadBalancerClass = desired.Spec.LoadBalancerClass
			}
		} else {
			svc.Spec.LoadBalancerClass = nil
			svc.Spec.AllocateLoadBalancerNodePorts = nil
		}
		if desired.Spec.ExternalTrafficPolicy != corev1.ServiceExternalTrafficPolicyLocal {
			svc.Spec.HealthCheckNodePort = 0
		}
		return controllerutil.SetControllerReference(srv, svc, r.Scheme)
	})
	return svc, err
}

// serversForSecret enqueues the Servers in the Secret's namespace that read or own it, so a
// rotated token or certificate takes effect without waiting for the next requeue.
func (r *ServerReconciler) serversForSecret(ctx context.Context, obj client.Object) []reconcile.Request {
	servers := &frpv1alpha1.ServerList{}
	if err := r.List(ctx, servers, client.InNamespace(obj.GetNamespace())); err != nil {
		return nil
	}
	var requests []reconcile.Request
	for i := range servers.Items {
		if slices.Contains(frps.SecretNames(&servers.Items[i]), obj.GetName()) {
			requests = append(requests, reconcile.Request{NamespacedName: client.ObjectKeyFromObject(&servers.Items[i])})
		}
	}
	return requests
}

// latestEventMessage returns the message of the most recent event, or "".
func latestEventMessage(events []corev1.Event) string {
	if len(events) == 0 {
		return ""
	}
	at := func(e corev1.Event) time.Time {
		if !e.LastTimestamp.IsZero() {
			return e.LastTimestamp.Time
		}
		return e.EventTime.Time
	}
	sort.Slice(events, func(i, j int) bool { return at(events[i]).Before(at(events[j])) })
	return events[len(events)-1].Message
}

// SetupWithManager sets up the controller with the Manager.
func (r *ServerReconciler) SetupWithManager(mgr ctrl.Manager) error {
	if r.Recorder == nil {
		r.Recorder = mgr.GetEventRecorderFor("server-controller")
	}
	if r.LoadBalancerError == nil {
		clientset, err := kubernetes.NewForConfig(mgr.GetConfig())
		if err != nil {
			return fmt.Errorf("failed to create clientset: %w", err)
		}
		// Read live with a field selector: caching every Event in the cluster would be costly.
		r.LoadBalancerError = func(ctx context.Context, namespace, service string) (string, error) {
			events, err := clientset.CoreV1().Events(namespace).List(ctx, metav1.ListOptions{
				FieldSelector: "involvedObject.kind=Service,involvedObject.name=" + service + ",reason=SyncLoadBalancerFailed",
			})
			if err != nil {
				return "", err
			}
			return latestEventMessage(events.Items), nil
		}
	}
	if r.ServiceMonitorAvailable == nil {
		mapper := mgr.GetRESTMapper()
		r.ServiceMonitorAvailable = func() bool {
			_, err := mapper.RESTMapping(schema.GroupKind{Group: "monitoring.coreos.com", Kind: "ServiceMonitor"}, "v1")
			return err == nil
		}
	}
	return ctrl.NewControllerManagedBy(mgr).
		For(&frpv1alpha1.Server{}).
		Owns(&corev1.Pod{}).
		Owns(&corev1.Service{}).
		Watches(&corev1.Secret{}, ctrlhandler.EnqueueRequestsFromMapFunc(r.serversForSecret)).
		Complete(r)
}
```

```go
// waitServer waits for a Server condition (reason "" matches any) and returns the Server.
func (c *Case) waitServer(name, condType string, status metav1.ConditionStatus, reason string) *frpv1alpha1.Server {
	c.t.Helper()
	var got *frpv1alpha1.Server
	eventually(c.t, 3*time.Minute, fmt.Sprintf("Server %s/%s %s=%s %s", c.NS, name, condType, status, reason), func(ctx context.Context) error {
		s := &frpv1alpha1.Server{}

			return err
		}
		cond := meta.FindStatusCondition(s.Status.Conditions, condType)

			return fmt.Errorf("condition is %+v", cond)
		}
		got = s
		return nil
	})
	return got
}
```
