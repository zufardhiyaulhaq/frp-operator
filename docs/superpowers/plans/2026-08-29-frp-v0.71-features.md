# frpc v0.71.0 Upgrade and New Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump frpc to v0.71.0 and expose four new frp features — `enabled` on Upstream/Visitor, automatic `clientID`, `transport.wireProtocol`, and `loadBalancer` on HTTP/HTTPS upstreams — for frp-operator v0.9.0.

**Architecture:** Every feature follows the existing four-layer pattern: CRD type (`api/v1alpha1`) → internal model (`pkg/client/models`) → CR→model transform (`NewConfig`) → frpc TOML template (`pkg/client/utils/template.go`). Two small helpers are extracted in the model layer (`isEnabled`, `resolveLoadBalancer`) and one new exported function (`VisitorServicePorts`) lets the controller skip disabled visitors. All changes are additive.

**Tech Stack:** Go 1.23 · Kubebuilder v3 / controller-gen · controller-runtime (fake client in tests) · Go `text/template` · Helm

**Spec:** `docs/superpowers/specs/2026-08-29-frp-v0.71-features-design.md`

## Global Constraints

- frpc image: `fatedier/frpc:v0.71.0`; operator release `v0.9.0`; chart `version: 1.7.0`, `appVersion: 0.9.0`, `operator.tag: "v0.9.0"`.
- Existing CRs must render byte-identical TOML except for the new `clientID = "..."` line.
- `enabled` is `*bool` with `+kubebuilder:default=true`; `nil` means enabled; `enabled = false` is emitted only when disabled.
- `clientID` is always `<namespace>/<name>` of the Client CR and is not user-settable.
- `wireProtocol` has **no** CRD default; the TOML key is emitted only when set; allowed values `v1`, `v2`.
- `loadBalancer` reuses `api/v1alpha1.LoadBalancer` and `models.LoadBalancerConfig`; there is no weight.
- **Do not commit.** The user commits after review. Every task ends at "tests green"; there are no commit steps.
- **Go toolchain:** on this machine `go` may resolve to 1.24 while `GOROOT` is 1.23. If `make test` fails with `compile: version "go1.23.12" does not match go tool version`, prefix commands with `PATH=$HOME/.asdf/installs/golang/1.23.12/go/bin:$PATH`.
- `make generate manifests` must be run after any `api/v1alpha1` change; `charts/frp-operator/crds/crds.yaml` is then synced by replacing each CRD document wholesale (Task 8).

// VisitorServicePorts returns the bind ports of enabled STCP/XTCP visitors, in input order.
// Disabled visitors are excluded so they do not occupy a port on the client Service.
func VisitorServicePorts(visitorObjects []frpv1alpha1.Visitor) []int {
	ports := []int{}
	for _, visitor := range visitorObjects {
		if !isEnabled(visitor.Spec.Enabled) {
			continue
		}
		if visitor.Spec.STCP != nil {
			ports = append(ports, visitor.Spec.STCP.Port)
		}
		if visitor.Spec.XTCP != nil {
			ports = append(ports, visitor.Spec.XTCP.Port)
		}
	}
	return ports
}
