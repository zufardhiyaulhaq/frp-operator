# Environment Variables on the Client Pod

**Date:** 2026-08-29
**Status:** Approved

## Background

Under high load `frpc` can consume enough memory to be OOM-killed. Go's runtime honors the
`GOMEMLIMIT` environment variable as a soft heap limit, which makes the garbage collector work
harder before the container hits its cgroup limit. Today the `Client` CRD's `podTemplate` exposes
`resources`, scheduling and security fields, but no way to set container environment variables,
so users would need a mutating webhook to inject `GOMEMLIMIT`.

## Goal

Add an optional `podTemplate.env` field to the `Client` CRD that is copied verbatim onto the
`frpc` container. The change is additive and non-breaking.

## Design decisions

1. **Generic passthrough, no operator magic.** The operator does not auto-derive `GOMEMLIMIT`
   from `resources.limits.memory`. Users set it explicitly, either with a literal value or a
   `resourceFieldRef` to `limits.memory`. This keeps behavior predictable and the surface small.
2. **Full `corev1.EnvVar`.** Reusing the upstream type gives `value` and every `valueFrom` source
   (`secretKeyRef`, `configMapKeyRef`, `fieldRef`, `resourceFieldRef`) for free, with the CRD
   schema generated by controller-gen.
3. **No `envFrom`.** Not needed for the motivating use case; can be added later the same way.
4. **Replace, not merge.** The builder sets `container.Env = podTemplate.Env`. The operator adds no
   env vars of its own, so there is nothing to merge with.

## Changes

### 1. CRD type — `api/v1alpha1/client_types.go`

Append to `ClientSpec_PodTemplate`:

```go
// +optional
// Env is a list of environment variables to set in the FRP client container (e.g. GOMEMLIMIT)
Env []corev1.EnvVar `json:"env,omitempty"`
```

### 2. Pod builder — `pkg/client/builder/pod_builder.go`

Next to the existing `Resources` block:

```go
if n.PodTemplate != nil && n.PodTemplate.Env != nil {
    container.Env = n.PodTemplate.Env
}
```

- `api/v1alpha1/zz_generated.deepcopy.go` via `make generate`

## Testing

- `pkg/client/builder/pod_builder_test.go`:
  - `TestPodBuilder_WithEnv` — literal and `resourceFieldRef` env vars land on the `frpc` container.
  - `TestPodBuilder_NoEnvByDefault` — an empty `PodTemplate` leaves `container.Env` empty.
- `make test`, `make lint`.
- Manual: `make install run` against the orbstack context, apply the example, confirm
  `kubectl get pod <name>-frpc -o yaml` shows the env and frpc logs are healthy.

## Out of scope

- Automatic `GOMEMLIMIT` derivation
- `envFrom`
- Env vars on any container other than `frpc` (there is only one)
